# PaperDesk 1.1.2 使用说明

## 安装与第一次打开

运行 PaperDesk-1.1.2-x64.exe，安装目录可选 D:/Apps/PaperDesk。免安装 ZIP 解压到任意目录后运行 PaperDesk.exe。应用与资料库分开，升级和卸载不会主动删除资料库。

第一次打开时自设用户名和非空密码，不需要邮箱，允许简单密码，默认记住登录。每台新设备都要独立设置相同用户名和密码，再在“同步”中配对。不要把正在使用的数据库直接放进网盘。

默认资料库：D:/PaperDeskData；没有 D 盘时使用用户主目录下的 PaperDeskData。实际位置可在设置中查看。PAPERDESK_DATA_DIR 可指定其它路径。

## 导入、阅读与 Markdown 笔记

- 导入 PDF 会按文件 SHA-256 和规范化 DOI 去重；同名但内容不同只提示候选，不擅自合并。
- 默认从 PDF 元数据或首页识别论文标题并命名。编辑标题会更新显示名和文件名。文件名末尾短编号避免同名覆盖。
- 顶部左侧两个按钮分别收起主侧栏和文献列表，再点即可恢复。
- 阅读、笔记、边读边记分别显示 PDF、独立写作区和左右并排布局。在并排布局点击“收起 PDF”可专心写笔记。
- 顶部“专注阅读”隐藏额外界面；Esc 恢复。右上角全屏按钮或 F11 切换桌面全屏，Esc 退出。
- 两处分界线均可拖动：文献列表与详情之间、边读边记的 PDF 与笔记之间。比例分别记住；双击恢复默认，选中分界线后用左右方向键微调。
- Markdown 使用单区实时编辑，直接点击文字修改。停止输入约 1 秒自动保存，Ctrl+S 立即保存；离开当前文献和退出前会等待保存完成。底部显示待保存、保存中、已保存或失败。失败时内容保留在编辑器中，点击保存重试；同步仍由你手动发起。
- 点击笔记工具栏的问号查看语法、公式和保存说明。光标所在处显示必要的 Markdown 标记，移开后自动排版，无需切换模式。
- PDF 阅读笔记和独立笔记都使用 Markdown，可通过 paperdesk://paper/文献编号互相引用。资料库 notes 目录可交给 Obsidian 编辑；不要改动数据库或内部编号。
- 同步期间两端同时修改笔记，会保留双方版本并显示冲突段落，整理后保存即可。

## 知识库

默认“本地检索”无需模型接口，可选全部、论文、笔记。论文搜索包括原文与元数据；笔记包括论文的阅读笔记和独立笔记。点击论文结果跳到对应页，点击笔记结果打开笔记。

“文献问答”使用设置中分配的问答模型，检索文献和笔记后回答并附来源。未配置模型、没有证据或接口失败时会明确说明。扫描 PDF 需要先用外部 OCR 加文字层再导入。

“更新知识库”构建索引。配置嵌入模型后可建立语义索引；更换模型后请重新构建。模型配置详见 [模型配置指南](MODELS.md)。

## 手动多设备同步

同步仅在点击时进行。退出桌面窗口前，如仍有本地更改，会提醒选择目标同步；也可只退出。多个目标分别记录进度，同步一个目标不代表其它目标已更新。

### SSH

1. 在两台电脑安装 1.1 或更新版本，并使用相同的 PaperDesk 名字与密码。
2. 在系统中配置 SSH 密钥连接，先确认终端可以执行 ssh 系统用户名@地址。
3. 在“同步 → 添加同步目标”填写名字，选择 SSH。
4. 填写 SSH 地址、端口、远程安装目录（例如 D:/Apps/PaperDesk）与远程资料库目录（例如 D:/PaperDeskData）。远程安装目录不是工程源代码目录。
5. 测试连接，然后点击同步；首次输入 PaperDesk 用户名和密码完成两端验证，可记住配对。SSH 密钥不代替应用账号验证。
6. 可添加家中电脑、工位机等多个目标，逐个手动同步。“允许访问本机的设备”可以撤销其它设备的权限。

系统账号（如 researcher）用于 SSH；PaperDesk 用户名用于文献库配对，两者可不同。旧版远程端必须先升级；不会再把密码哈希复制到另一台设备，也不会自动创建对方账号。

### 加密同步文件夹：OneDrive、NAS、移动硬盘

1. 在网盘或 NAS 中建立专用空文件夹，或者在移动硬盘建立文件夹。
2. 每台电脑添加“共享文件夹”目标，填写该共享目录在本机的完整路径。不同电脑的路径可以不同。
3. 第一次同步输入相同的应用用户名与密码；可记住解锁信息。
4. 在 A 电脑点同步，等网盘客户端传输完成；在 B 电脑点同步。B 编辑后再点同步，等传输完成，再在 A 电脑同步。

PaperDesk 写入加密的 .pdsync 文件，每台设备使用自己的文件，避免互相覆盖。PDF、文献记录和笔记都在加密包里；账号密码哈希、API Key、登录会话和模型配置不会同步。应用密码允许简单，但简单密码对离线猜测的抵抗力较弱。

文件夹同步完成表示已读取当前可见包并发布本机包，无法替网盘判断远程传输是否完成。请确保文件已下载到本地，不要只保留云端占位符。当前单次同步包上限 1 GB。

### 改密码与恢复

修改密码仅作用于当前设备，并撤销本机已记住的同步配对。请在所有设备分别改成同一新密码，再重新配对 SSH。

加密同步包使用原密码派生的密钥。改密码后，所有设备应选用一个新的空同步文件夹，从仍完整的资料库重新发布；旧加密包保留为备份，不会自动重加密或删除。

### 备份

同步会传播有意的删除，不能代替独立备份。常规手工备份应关闭窗口并停止后台服务，再复制整个资料库。关闭窗口后后台可能仍在运行：请在任务管理器中确认并结束属于此安装目录的 PaperDesk Node 后台，再复制完整资料库。备份包含账号和配置，应存放在自己控制的独立目录。

## Hermes 与 QQ

Hermes 可以查论文、读取页码原文、讨论后追加笔记。它使用工位机上的文献库；手机 QQ 对话仍由已有 Hermes QQ 连接负责。设置页提供按本机安装位置生成的配置和四步引导，详见 [Hermes 接入指南](HERMES.md)。

关闭 PaperDesk 窗口后，本地后台继续运行供 Hermes 使用；不会因此自动同步。
## Markdown 与公式速查

| 内容 | 写法 |
| --- | --- |
| 标题 | `# 标题`，井号后留半角空格 |
| 粗体、斜体 | `**重点**`、`*说明*` |
| 列表、任务 | `- 条目`、`- [ ] 待办`、`- [x] 完成` |
| 引用 | 行首写 `> 引文` |
| 链接 | `[名称](https://example.com)` |
| 行内公式 | `$E=mc^2$` 或 `\(E=mc^2\)` |
| 独立公式 | `$$` 与 `$$` 之间，或 `\[ ... \]` |

例如下面的公式块会离线排版为分式和求和：

```tex
$$
\frac{1}{N}\sum_{i=1}^{N} x_i
$$
```

反引号包围的是代码，会原样显示，公式不要放进代码块。行首四个空格也会成为代码块；全角 `＃` 不等于半角 `#`。表格需要 `| --- | --- |` 表头分隔行，段落之间空一行。金额可以写 `\$100`。公式语法错误或 KaTeX 不支持的命令会保留源码并标红，不会让整篇笔记消失。

当前不支持 Obsidian 插件、`[[双链]]`、`==高亮==`、callout 和 Mermaid 图；可用普通链接、粗体和引用替代。支持的公式命令见 [KaTeX 官方文档](https://katex.org/docs/supported)。

## 单区实时编辑（1.1.2）

笔记已取消“编辑／分栏／预览”切换，直接在一个区域内点击、输入和查看排版。标题、表格、列表、公式在光标移开后自动排版；点击该处会显示必要的 Markdown 标记，便于修改，和 Obsidian 的实时编辑方式类似。Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+Z 撤销、Ctrl+Y 重做。公式和表格点击后可编辑其 Markdown 原文。Ctrl+A 复制整篇时仍得到原始 Markdown。

自动保存和 PDF／笔记之间的拖动调宽继续有效。只打开或浏览笔记不会改写现有 Markdown 文件。
